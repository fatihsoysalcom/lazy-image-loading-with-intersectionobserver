# Lazy Image Loading With IntersectionObserver

This example demonstrates lazy loading of images in a web page using the IntersectionObserver API. Images with a `data-src` attribute will only load their actual source when they become visible in the viewport, improving initial page load performance.

## Language

`html`

## How to Run

Save the code as `index.html` and open it in a web browser. Scroll down to see the images load as they enter the viewport.
